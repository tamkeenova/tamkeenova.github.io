# Islam Ragab portfolio

Static personal site for Islam Ragab Eid (Arabic and English), served at https://tamkeenova.github.io/islam/ from the `islam/` folder of this repo. Content lives in `islam/data/*.json` and is edited through the Decap CMS editor at https://tamkeenova.github.io/islam/admin/ (Decap Turbo backend, free plan).

The repo root holds only redirect pages: `/` -> `/islam/` and `/admin/` -> `/islam/admin/`, so older links keep working.
